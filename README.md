# My Math Python Package

A beginner-friendly custom Python package created to practice Python modules, packages, functions, imports, recursion, and basic error handling.

## Modules

### `basic.py`
Contains basic arithmetic operations:
- Addition
- Subtraction
- Multiplication
- Division

### `advanced.py`
Contains advanced mathematical functions:
- Power
- Square
- Cube
- Square root
- Factorial using recursion

### `geometry.py`
Contains basic geometry calculations:
- Area of circle
- Area of rectangle
- Area of triangle

### `statistics.py`
Contains basic statistical functions:
- Mean
- Median
- Maximum
- Minimum

## Concepts Practiced

- Python modules
- Python packages
- `__init__.py`
- Import statements
- Functions
- Recursion
- Error handling
- Code organization

## Example Usage

```python
from my_math import add, square, area_circle, mean

print(add(10, 5))
print(square(5))
print(area_circle(5))
print(mean([10, 20, 30]))
```
Project Purpose

This project was created as a hands-on Python practice project to understand how multiple Python modules can be organized and used together as a package.
